# Sovereign Debt under Rare Disasters

## Overview

This repo implements the calibration pipeline for my undergraduate honors thesis at NYU, *Sovereign Debt under Rare Disasters*. The project estimates how rare, large economic disasters affect sovereign credit spreads.

At a high level the pipeline does four things:

1. **Extracts disaster intensities** from country-level equity valuation data (CAPE ratios). The CAPE yield implied by a rare-disaster asset-pricing model is inverted to back out a time-varying disaster intensity λ for each country.
2. **Decomposes intensities** into a global component (shared across all countries, extracted via PCA) and a country-specific component.
3. **Calibrates a default hazard model** to sovereign CDS spreads. Per-country parameters ($h_0$, $η_i$, $η_g$) govern how much baseline, country-specific, and global disaster risk each sovereign's credit spread reflects.
4. **Produces figures and tables** for the thesis, including model vs observed spread comparisons, flight-to-quality dynamics, simulated spread paths, and term structure diagnostics.

This is a research calibration pipeline, not production software.

## Data requirements

### What data is needed

| File | Location | Description |
|------|----------|-------------|
| `country_cape_panel.csv` | `calibration/raw_data/` | Monthly CAPE panel for 15 countries (US, UK, JP, DE, MX, ES, FR, BR, ID, MY, SE, NL, TH, TR, CL), built from LSEG equity index prices, P/E ratios, and CPI |
| `CDS spreads.csv` | `calibration/raw_data/` | Sovereign CDS spreads at 1Y, 2Y, 3Y, 5Y, 7Y, 10Y tenors from LSEG |
| `shiller CAPE.csv` | `calibration/raw_data/` | U.S. CAPE time series from Robert Shiller's dataset (used only for validation) |

### Git tracking

The `.gitignore` excludes `*.csv` files, so **raw data CSVs are not committed to the repository**. You need to either:

- Regenerate `country_cape_panel.csv` using the LSEG step (requires credentials), or
- Obtain the raw data files separately and place them in `calibration/raw_data/`.

The CDS spreads CSV (`CDS spreads.csv`) and Shiller CAPE CSV must be provided manually — they are not fetched automatically.

### LSEG Workspace access

Step 1 of the pipeline (`lseg_cape.py`) calls the LSEG Data API (`lseg.data`) to pull monthly equity index prices, P/E ratios, and CPI for each country. This requires:

- An active LSEG Workspace license with API access
- The `lseg-data` Python package installed and configured

If you already have `country_cape_panel.csv` in `calibration/raw_data/`, you can skip this step entirely using `--skip-lseg`.

There is no `requirements.txt` in the repo. The required packages, inferred from imports, are:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install numpy pandas scipy matplotlib scikit-learn
```


## Running the pipeline

### Full pipeline (with LSEG data fetch)

```bash
python -m calibration.run_calibration
```

### Full pipeline (skip LSEG, use existing raw data)

```bash
python -m calibration.run_calibration --skip-lseg
```

Use this if `calibration/raw_data/country_cape_panel.csv` already exists.

### What each step does

| Step | Module | Description |
|------|--------|-------------|
| 1 | `calibration.lseg_cape` | Fetches monthly equity index prices, P/E ratios, and CPI from LSEG for 15 countries. Computes 10-year rolling CAPE. Writes `raw_data/country_cape_panel.csv`. |
| 2 | `calibration.extract_intensities` | Inverts the model's CAPE-yield relation to back out disaster intensity λ per country-month. Runs PCA to extract the global factor and decomposes into λ_global and λ_country. Writes `processed_data/intensities.csv`. |
| 3 | `calibration.build_panel` | Merges disaster intensities with sovereign CDS spreads, aligns country names and dates, and writes `processed_data/panel.csv`. |
| 4 | `calibration.calibrate_cds` | For each country, runs a nonlinear least-squares fit of (h₀, η_i, η_g) to minimise the distance between model-implied and observed CDS spreads across all tenors and dates. Countries are calibrated in parallel. Writes `results/parameters.csv` and `results/model_vs_observed.csv`. |
| 5 | `calibration.plot_results` | Produces diagnostic figures (model vs observed, term structures by disaster state, parameter heterogeneity). Writes PNGs to `results/`. |

The pipeline stops immediately if any step fails.

### Individual modules

You can also run each step independently:

```bash
python -m calibration.extract_intensities
python -m calibration.build_panel
python -m calibration.calibrate_cds
python -m calibration.plot_results
```

## Notes for reproducing thesis results

- Use `--skip-lseg` if the CAPE panel is already present in `calibration/raw_data/`. Rerunning the LSEG step fetches fresh data from LSEG and will overwrite the existing file.
- Rerunning the pipeline overwrites all processed outputs and results.
- The CDS spreads file must be named exactly `CDS spreads.csv` (including the space) and placed in `calibration/raw_data/`.
- Figures from `calibration/results/figures/` and tables from `calibration/results/tables/latex/` can be copied directly into the thesis LaTeX folder.
- The `final/` directory contains the previously exported final thesis figures.

## Troubleshooting

**`ModuleNotFoundError: No module named 'core'`**
Run all commands from the repo root (`honors/`), not from inside `calibration/`. The `core` and `models` directories are packages at the repo root.

**`FileNotFoundError` for a raw data CSV**
Check that `calibration/raw_data/` contains the required files. Large CSVs are excluded from git by `.gitignore` and must be provided separately.

**LSEG step fails with authentication error**
You need an active LSEG Workspace session. Install `lseg-data`, configure your credentials, and ensure Workspace is running. Alternatively, use `--skip-lseg` if the CAPE panel is already available.

**Import errors on startup**
Activate the virtual environment (`source .venv/bin/activate`) and confirm all packages are installed.

**Calibration does not converge for some countries**
A convergence failure is reported in `results/parameters.csv` under the `converged` column. It does not stop the pipeline; those countries are excluded from downstream plots and tables.
